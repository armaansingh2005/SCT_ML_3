# 🐱🐶 Cat vs Dog Image Classification using SVM

## 📌 Project Overview

This project focuses on developing a Machine Learning model using **Support Vector Machine (SVM)** to classify images into two categories: Cats and Dogs.

The project demonstrates image preprocessing, feature extraction, model training, and image classification using Python and Scikit-learn.

Developed as part of the **SkillCraft Technology – Machine Learning Internship (Task 3)**.

## 🎯 Project Objectives

- Develop an image classification model using SVM.
- Classify images into Cats and Dogs categories.
- Perform image preprocessing and feature extraction.
- Train and test the machine learning model.
- Evaluate classification performance.
- Understand the practical applications of supervised machine learning.

## 🛠️ Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- OpenCV / PIL (if implemented)

## 📂 Dataset Description

**Dataset:** Cats and Dogs Image Dataset

The dataset contains images belonging to two categories:

| Category | Description |
|---|---|
| Cats | Images of cats |
| Dogs | Images of dogs |

The dataset is used to train and evaluate the image classification model.

## ⚙️ Project Workflow

1. **Dataset Collection:** Load the Cats and Dogs image dataset.
2. **Image Preprocessing:** Resize images into a consistent dimension.
3. **Feature Extraction:** Convert images into numerical representations.
4. **Data Preparation:** Prepare training and testing datasets.
5. **Model Building:** Implement Support Vector Machine.
6. **Model Training:** Train the classifier using labeled images.
7. **Prediction:** Classify images as Cats or Dogs.
8. **Model Evaluation:** Evaluate performance using classification metrics.

## 🤖 Machine Learning Algorithm

### Support Vector Machine (SVM)

Support Vector Machine is a supervised machine learning algorithm used for classification and regression tasks.

In this project, SVM learns patterns from image features and uses them to distinguish between cat and dog images.

**Key Concepts:**
- Hyperplane
- Support Vectors
- Maximum Margin
- Classification
